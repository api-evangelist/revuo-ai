Revuo is a B2B SaaS directory built for the AI‑citation era, providing structured capability listings that are continuously verified. It offers an agent‑callable public MCP endpoint exposing tools and product data, enabling LLMs to cite reliable software recommendations. The platform indexes products across categories like PIM, Tender Management, Billing & Invoicing, and Headhunter CRM, with transparent editorial and paid placement labeling.

**Areas:** B2B · SaaS · Directory · AI · MCP

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Revuo: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
